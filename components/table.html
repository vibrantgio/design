Table

The data table is .table on a native <table>. The grid grounds on --color-surface; the header band fills neutral-300 under neutral-700 label-large text. Header and body rows are each exactly --density-control-height tall — the row rule, so compact density re-pitches the whole grid — and every row closes with a 1 px --color-divider rule drawn inside its height. Cells inset horizontally by --space-3; body text is body-medium at the text pin. Rows separate by the rules alone — there is no zebra stripe. Column widths are fixed-layout: pin a column with a <col> width, leave the rest to flex.

Sort affordance

The three header states: at rest a .sortable header shows no glyph — the affordance is the pointer cursor; the active column shows the chevron, apex up for ascending, down for descending. The cycle is none → ascending → descending → none.

Compact density

The same markup inside a class="compact" wrapper: --density-control-height drops from 36 to 28 px and the header band and every row re-pitch with it. Density is the one size axis — the paddings and rules stay put.
