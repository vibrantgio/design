Table

The data table is .table on a native <table>. The grid stands on --platform-control-background; the header band takes no fill of its own — on this platform a table's header is the content's fill under --platform-header-text in label-large, closed by --platform-separator along its foot. Header and body rows are each exactly --density-row-height tall — the platform's stacked row, 20 px comfortable, which is shorter than a control — so compact density re-pitches the whole grid, and every body row closes with a 1 px --platform-grid rule drawn inside its own height. Cells inset horizontally by --space-3; body text is body-medium in --platform-label. Every second body row is laid on --platform-alternating-content-background, which is what Finder's list view draws. Column widths are fixed-layout: pin a column with a <col> width, leave the rest to flex.

Sort affordance

The three header states: at rest a .sortable header shows no glyph — the affordance is the pointer cursor; the active column shows the chevron, apex up for ascending, down for descending. The cycle is none → ascending → descending → none.

Compact density

The same markup inside a class="compact" wrapper: --density-control-height drops from 36 to 28 px and the header band and every row re-pitch with it. Density is the one size axis — the paddings and rules stay put.
