Type

Every type role at its real size, weight and line height, styled through the --font-<role>-* tokens. The face is the family the tokens name — Roboto, and Roboto Mono for the code style — via var(--font-family) and var(--font-family-code); the browser must have them installed, otherwise the system fallback face renders at the same metrics. A role adds no tracking: the typeface's own spacing sets the text.
