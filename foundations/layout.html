Density

Two published settings share one variable family: :root carries comfortable, and a .compact class block overrides every per-setting metric of the --density-* family the way .dark overrides the colours — the right column below is the same markup inside a class="compact" wrapper. The dashed outline is --density-min-hit-target, the WCAG 2.5.5 pointer-target floor: it is not overridden, so compact shrinks the drawn control but never the clickable area.

Elevation

Elevation is tonal, and it climbs toward the light: in both schemes, every level is lighter than the one beneath it — one rule, no mirror. --elevation-* is the surface fill and the default cue, resolved per scheme, so both blocks state their own six. The levels run from the backdrop up toward the reader: the bare window plane, the chrome a window's furniture wears, the content surface, then raised insets and floating transients. Read the cards below left to right and the fill gets lighter, in either scheme. The levels stop at 3 — desktop has no six-deep stack.

The opt-in shadow

The dp shadows survive as --shadow-N for floating transients only — menus, dialogs, tooltips: a float adds its shadow on top of its tonal fill; resting surfaces use the fill alone.
